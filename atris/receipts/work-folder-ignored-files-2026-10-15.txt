Finished copies lose ignored files on cleanup, 2026-10-15

Finding: cleanup removes a finished, merged copy with a plain git folder
removal. Git treats ignored files as disposable, and the status check cleanup
relies on does not list them, so the copy looks clean and its ignored files
are deleted without a word in the preview or the apply output.
