## the change

Block interpreter one-liners that pair a network call with reading environment variables, so python, node, perl, ruby and php can't leak keys around the existing rules.

The guard only reads network programs like curl and nc, so a key sent from inside python3 -c, node -e or ruby -e passes. A single pattern that needs both a network call and an env read in the same command covers the seen python urlopen case and the same shape in other interpreters, and it leaves plain env reads and plain fetches alone.
