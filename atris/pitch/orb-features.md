# The Orb Slate, next 10-15 features

> Source: july7synth.md + the orb neural-net visual. Each feature stands on a primitive
> that already works. Order = rough leverage, not sequence.
> Pinned wish: "activate the orb architecture end to end" (2026-07-08).

## The forward pass (the product)

1. **The Interview**, any fuzzy ask gets opinionated blanks ("best could mean X, Y, Z, I'd bet Y, right?") before dispatch. The input edge of the orb. Stands on: wish-audit clarity gate, taste doctrine.
2. **One command, one lap** (shipped 2026-07-09), `atris "<any sentence>"` scopes one task, resumes duplicates atomically, builds in an OS-isolated bundle-seeded sandbox, reruns one frozen allowlisted verifier without network access, requires a distinct cold-reader validator, materializes the verified tree in Review without changing protected refs, and answers in plain english or JSON with a receipt. Stands on: wish interview, engine registry, scoped dispatch, receipt evidence.
3. **Weights that update**, receipts auto-tune routing nightly: which engine/prompt/model won per task shape gets repinned without a human. The gradient arrow made real. Stands on: scorecards, experiments-on-tick, ROUTING.md.
4. **Watch the forward pass**, live web view of the neural-net diagram: your ask lighting up orb → hidden layer → validator → answer. The demo that sells itself. Stands on: atrisos-web, tasks.projection.json, mission events.

## The human edge

5. **Plain-english approval queue**, everything waiting-on-you is one sentence each, approvable from phone or SMS. The output node as a consumer surface. Stands on: autoland, needs-human, iMessage digest.
6. **Day loop for everyone**, morning card and evening close written by the system, cloned per operator. Stands on: day loop (live on Keshav, Justin next).
7. **Second-brain check-ins**, the system schedules interviews with you to keep its memory current, instead of memory rotting silently. Stands on: brain compile, closure engine, staleness gate.

## The business computer

8. **Drop-in install**, atris/ folder lands in any company repo and its loops connect with zero insider knowledge. Stands on: golden-path mission, folder-is-the-brain.
9. **Loop packs, sold as laps**, the DoorDash weekly-business-review and Pallet recruiting loops packaged for the N+1 customer. Revenue = laps, not tokens. Stands on: apps, det scripts, deck engine.
10. **Receipts as compliance**, the receipt ledger doubles as SOC2-grade evidence: what acted, on what authority, with what outcome. Verification becomes the product. Stands on: receipts, security-review.

## The economy

11. **The FDE exam**, hackerrank for forward-deployed engineers, scored on real Atris laps. A hiring product and a data engine at once. Stands on: agents-v1 bench, AgentGrads eval.
12. **Self-staffing**, the system posts shifts, members claim them, XP pays out; humans and AI on the same ladder. Stands on: AgentGrads shifts, career XP.
13. **Wish → company**, friends pool capital into a wish; the system validates, builds, and grows it with the founders as the approval queue. Stands on: wish loop, missions, autoland.

## The flywheel

14. **Overnight autoresearch as a dial**, the pulse loop that prunes and strengthens the brain nightly, exposed as something a customer turns up or down. Stands on: pulse loop, upkeep, usage reaper.
15. **Every lap launches itself**, shipped work auto-produces the card, reel, and post; the system does its own GTM. Stands on: card, reel, launch-vid, daily launches.
