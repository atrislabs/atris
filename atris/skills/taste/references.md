# References

Ideas worth learning from. We never name the source and never copy its lines or look. Inspiration stays inspiration. Back to [SKILL.md](SKILL.md).

- **Three that land as one.** Name each part alone before revealing they are a single thing. Never borrow the famous lines that made this move known.
- **Problem and answer in one sentence.** State the problem first and the answer second, with the answer in a quieter color.
- **Art made from the product.** Draw with the product's own material, like rows of marks that read as a stream of work, instead of stock pictures.
- **Three words in a loop.** Explain the product as a short cycle of three verbs.
- **One loud button and one quiet one.** A solid main action sits next to a flat secondary one.
