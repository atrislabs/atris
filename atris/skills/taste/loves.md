# What the owner loves

From a design taste test on 2026-11-07 with 65 picks and six loves. Back to [SKILL.md](SKILL.md).

## The six, described

- A white gallery page with sharp black type and huge editorial photos. The owner's words: "Feels cinematic, sexy, less text. I can understand."
- A stark editorial poster, like a printed sheet pinned to a wall.
- A welcome screen split into two calm halves, with the product name doing all the work.
- A dark intro screen with one centered panel holding all the attention.
- A dark cinematic landing page with one full-bleed image in charge.
- A portfolio built almost only from oversized type on a warm paper color.

## What they share

One element dominates each screen. Each screen holds one idea with giant type sitting next to tiny text.

None of them explain much. You get it from the picture and one line.

The raw picks with names stay private on the owner's laptop in `~/.atris/taste/`.
