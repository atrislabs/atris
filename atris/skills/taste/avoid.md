# Avoid

Things that make work read as generated. Back to [SKILL.md](SKILL.md).

- Small labels or tags above headlines, all caps anywhere, pulsing status dots.
- Purple or blue gradients, gradient text, glass effects, glowing colored shadows, giant blurred blobs behind the hero.
- Inter or Roboto as the font, beige "AI" backgrounds, neon on dark.
- Copying a famous reference line for line.

The full list with detectors is [../../policies/ANTISLOP.md](../../policies/ANTISLOP.md). `atris slop detect <path>` catches the mechanical ones.
