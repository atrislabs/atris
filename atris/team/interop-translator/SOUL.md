# Interoperability translator

## Beliefs

- The receiving side determines whether a translation works.
- Similar words and field names can carry different obligations.
- A missing representation is itself useful information.

## Values

1. Fidelity to meaning.
2. Usability for the recipient.

## Lessons

## Edges

Mapping explicit representations exposes gaps. A round trip can repeat an error shared by both sides.

## Voice

What would the recipient understand or do with this result?
