# Seymour second neighborhood: exhaustive verification note (n <= 14)

Working note, produced by an automated agent pipeline on 2026-07-23.
Not peer reviewed. Nothing here has been checked by a human mathematician.

## What is claimed

No oriented graph on at most 14 vertices is a counterexample to Seymour's
Second Neighborhood Conjecture. Evidence:

- 63 CNF instances (whole-space for n = 6..10, minimum out-degree shards
  for n = 10..14 and beyond), all UNSAT under CaDiCaL 3.0.1, every proof
  checked by drat-trim. Receipts regenerated from scratch in the write-up
  session live in `receipts/`.
- An independent pipeline (nauty geng | directg -o | check_d6.c) exhausted
  all oriented graphs on n <= 8 (575,016,219 at n = 8), counts matching
  OEIS A001174 exactly, zero counterexamples.
- n = 15 and n = 16 have all shards UNSAT by CaDiCaL as well; their giant
  top-shard proofs (0.6 GB, 4.2 GB) were still re-verifying when the note
  was frozen. See Section "Beyond 14" in the note and check `receipts/`
  for the final word. n = 17, 18 are NOT claimed (top shards still solving).

We found no previously published exhaustive small-order verification of
the conjecture. An "n <= 7 published record" statement in an earlier
internal note could not be traced to any source and is withdrawn in this
note.

## Files

- `main.tex` : the note (compiles with `tectonic main.tex`; compiled OK on
  2026-07-23). Single file, embedded bibliography.
- `tables.tex` : per-instance table, generated by `gen_tables.py` from the
  artifacts in `../seymour-r4/`. Do not edit by hand.
- `gen_tables.py` : regenerates `tables.tex`.
- `verify_all_drat.sh` : re-runs drat-trim on every completed proof,
  writing receipts to `receipts/`. nice -n 15, bounded concurrency.
- `receipts/SUMMARY.txt` : one line per instance, VERIFIED/FAILED/SKIP.
- `receipts/*.drattrim.txt` : full drat-trim output per instance.
- `receipts/SHA256SUMS.txt` : checksums of every CNF, completed DRAT
  proof, and the load-bearing sources (encode.py, check_d6.c, cayley.py).
- `verify_run.log` : log of the verification sweep.

Artifacts (CNF, DRAT, solver logs, encoder, checkers) live in
`../seymour-r4/` (about 28 GB). The independent-pipeline checker and the
round-1 search code live in `../seymour-second-neighborhood/`; per policy
the round-1 search code is untrusted and load-bearing nowhere.

## Before submitting anywhere

Read Section "What an external reviewer must audit" in the note. Short
version: a human must audit the encoding-completeness argument, the shard
covering argument, the two-block lex-leader soundness argument, Lemma T
(or replace it with the citation to Fisher 1996), re-verify all proofs on
independent hardware (ideally with a formally verified DRAT checker such
as cake_lpr), read the two small load-bearing programs, and re-check the
literature history against primary sources.
