# Grounded Evidence Brief

Use this skill when investigating an unknown, comparing approaches, or benchmarking options before building.

## Workflow

1. Check local repo code and receipts first before external sources.
2. Cite exact `file:line` paths or primary URLs for every factual claim.
3. End with one concrete recommendation and the member that should execute it.
