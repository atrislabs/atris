# Atris Task Production Update

Tasks are becoming the atomic unit of work in Atris.

Not a checkbox. Not another chat window. A task is a small room where a human and agents can understand the goal, gather context, do the work, validate it, leave proof, and create the next task.

The important part is that the same task can exist locally in a repo, in the cloud for a team, in Swarlo for coordination, in Obelisk as a task room, and in the RL gym as training data.

The loop is simple:

```text
need something done
  -> create task
  -> gather context
  -> agent claims it
  -> work happens
  -> proof is attached
  -> review records the lesson
  -> next sharper task appears
```

This is how Atris turns work into a compounding system.

Every completed task teaches the company brain what worked, what failed, what proof mattered, and what should happen next.
